### A.2 Evidence vocabulary

- **IMPLEMENTED AND BOUNDED TECHNICAL CONTROL:** source plus tests demonstrate a narrow current behavior, not a deployment-wide guarantee.
- **SYNTHETIC/DETACHED TEST EVIDENCE:** isolated non-production evidence with no live patient or clinical authority.
- **PROPOSED UNAPPROVED CONTROL:** a review option, not selected architecture or policy.
- **ABSENT:** no current repository capability.
- **HUMAN DECISION PENDING:** accountable evidence/signature is missing and cannot be supplied by Codex.
- **LIVE NOT VERIFIED:** a canonical live acceptance outcome remains unproven.

Green CI, a successful scanner, typed permission, configuration flag, role constant or mock adapter never implies cross-platform security acceptance or production readiness.
