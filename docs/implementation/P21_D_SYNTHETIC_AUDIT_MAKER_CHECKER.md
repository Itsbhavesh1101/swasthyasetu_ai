## Implemented boundary

- Immutable synthetic proposal and checker-submission contracts bind closed machine identities,
  exact engineering object revision/hash, institution/source/purpose scope, and UTC chronology.
- A pure evaluator reconstructs both inputs and emits only an independence receipt. Exact metadata
  with distinct synthetic actors confirms independence; self-review or any metadata drift abstains.
- Immutable audit snapshots contain only canonical reconstructed independence receipts, enforce a
  16-receipt bound, and reject duplicate identities and semantic aliases.
- Canonical fingerprints bind every field; direct-constructor and forced-mutation paths are
  revalidated with stable content-free errors.
- `STAGING`, `PILOT`, and `PRODUCTION` fail before proposal, submission, receipt, identifier, or clock
  inspection.
- The module remains detached, unregistered, and absent from every route.
